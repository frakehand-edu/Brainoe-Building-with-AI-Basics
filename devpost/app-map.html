Exam-to-Quiz app map

A local Flask study app that turns supported text-based exam PDFs into an editable question bank, runs randomized MCQ quizzes, and saves progress in SQLite.

One real action through the app

Reference route

Use this route when changing the import-to-quiz behavior. It was exercised during the build; the file locations are a guide, not a requirement to memorize.

  1. app.py → import_questions receives the upload and stores the temporary preview in the Flask session.
  2. services/pdf_extractor.py → extract_pdf_text, then services/question_parser.py → parse_questions turn supported PDF text into validated records.
  3. templates/import_preview.html → edit_import_preview validates corrections; db/queries.py → add_questions saves confirmed records to SQLite.

To change this, start here

Change supported PDF formats

Start in services/question_parser.py and add a focused parser test in tests/test_app.py before changing the route.

Change quiz behavior

Start at app.py symbols start_quiz, quiz_question, and next_question; use the quiz flow tests as the safety net.

Change saved data or progress

Start in db/connection.py for tables and db/queries.py for reads/writes, then update persistence tests.

Change visual styling

Start in static/css/style.css and the relevant template. Keep the dark background, cream text, and accessible contrast unless the product direction changes.

A practice to reuse

The PDF parser was treated as a risk early: a representative sample and tests established what “usable extraction” meant before the quiz depended on it. On another project, identify the uncertain input or external boundary early, write one observable test for it, and only then build the surrounding experience.
